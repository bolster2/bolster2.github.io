NOTES AND SAFETY
    
 
    

    


    Good habits for every script
    

      

    • Start with set -euo pipefail, so the script stops on errors, unset variables and failed pipes.
      • 

    • Keep passwords out of scripts: use ~/.my.cnf, ~/.pgpass, environment files or a secret manager, with chmod 600.
      • 

    • Run destructive scripts as a dry run first, and log what they delete.
      • 

    • Use flock so two runs never overlap, and send failures to an alert channel.
      • 

    • A backup you have never restored is not a backup. Test restores on a schedule.
      • 

    • Lint with shellcheck script.sh before you put anything in cron.
    


    Cron schedule cheat sheet
    

    # m  h  dom mon dow   command
  0  2  *   *   *     every day at 02:00
  */15 * *   *   *     every 15 minutes
  0  */6 *   *   *     every 6 hours
  30 1  *   *   0     every Sunday at 01:30
  0  3  1   *   *     1st of every month at 03:00
  0  9  *   *   1-5   weekdays at 09:00
# edit:  crontab -e     list:  crontab -l     system jobs:  /etc/cron.d/
# always use absolute paths and redirect output:  >> /var/log/job.log 2>&1
    


    Handy one-liners
    

    # biggest directories under /var
sudo du -xh /var --max-depth=2 2>/dev/null | sort -rh | head -15

# files larger than 100 MB
sudo find / -xdev -type f -size +100M -printf '%s %p\n' 2>/dev/null | sort -rn | head -20 | numfmt --to=iec --field=1

# who is using a port
sudo ss -tulpn | grep ':8080'

# top 10 memory / CPU processes
ps aux --sort=-%mem | head -11
ps aux --sort=-%cpu | head -11

# find text in logs, last hour of an app log
grep -i "error" /var/log/app/app.log | tail -50
journalctl -u myapp --since "1 hour ago" --no-pager | tail -100

# count HTTP status codes in an nginx access log
awk '{print $9}' /var/log/nginx/access.log | sort | uniq -c | sort -rn

# find and kill a process by name
pgrep -af node ; pkill -f "node server.js"

# check which cron jobs ran
grep CRON /var/log/syslog | tail -20

# empty a huge log without deleting the file
: > /var/log/app/app.log

# quick backup of a file with a timestamp
cp -a /etc/nginx/nginx.conf /etc/nginx/nginx.conf.$(date +%F_%H%M)
